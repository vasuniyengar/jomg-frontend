# JOMG FRONTEND

## Instructions for setting up your JOMG FRONTEND APP

## 1. Clone your app
```
git clone <url>
```

## 2. Install your project dependecies
```
npm i 

Note: Node version should > 20
``` 

## 3. To start your application
```
npm run dev
```

**Hurray !! your app is running in localhost:3000**
